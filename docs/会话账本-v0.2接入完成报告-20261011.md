## 二、验证证据（P0 三条逐条实测）

### H1 签名交换 — "单方改不了"从口号变机制

```
① 缺对方签名 → verify() 判 invalid：
   {'ok': False, 'both_sigs_present': False,
    'reason': 'missing signature(s): 单方出示无效（H1）'}

② 对方签名对不上 → 验签失败：
   {'ok': False, 'sig_verified': False,
    'reason': 'signature verification failed (tampered or wrong signer)'}

③ 真实 Ed25519 闭环（关键）：
   pre_hash == final_hash : True   ← 签名对象 = 最终 ledger_hash
   加载后真实验签: {'ok': True, 'sig_verified': True}
```

> **修正了一个真问题**：初版签名对象是"交换前的 hash"，但账本最终 hash 会因 `signature_exchange` 事件改变 → 二者不等 → 用账本 hash 验签会失败。
> 修法：`signature_exchange` 事件标为 `hash_exempt`（不纳入哈希链，因其携带签名本身）→ **签名对象 == 最终 ledger_hash**，验签这才真正可用。

### H3 降级分级 — 实测

```
classify(local_state_mismatch)     = noise
classify(reordered_frame)          = noise
classify(unexpected_cipher_change) = suspicious
classify(ratchet_desync_prolonged) = suspicious
classify(plaintext_downgrade)      = critical
classify(signature_verify_failed)  = critical

```

### H4 全量记录 — 实测

```

```

## 四、签名交换时序（最终版）

```
会话结束（_do_hangup）
  ├─ record_close()
  ├─ pre_hash = 链尾 hash          ← 因 sig_exchange 不入链，pre_hash 即最终 hash
  ├─ my_sig = Ed25519_sign(私钥, pre_hash)
  ├─ WS 发送 {type:"ledger_sig", ledger_hash:pre_hash, sig:my_sig}
  ├─ 等待对方签名（3s 超时即放弃 —— 审计不因对方耍赖挂死会话）
  ├─ record_signature_exchange()   ← hash_exempt，不改变 hash
  ├─ ledger_hash = seal()
  ├─ attach_signatures(双方)
  └─ save() → <sid>.jsonl + <sid>.sig
```
