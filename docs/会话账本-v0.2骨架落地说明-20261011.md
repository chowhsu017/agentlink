## 二、P0 三条在代码里的落点

### H1 签名交换（解决"本地自嗨"）

- **数据结构**：账本含 `signatures: {initiator, responder}` + `verified_both`
- **校验逻辑**：`ledger.verify()` —— `require_peer_sig=True` 时，**缺对方签名 → 直接 invalid**
- **交换动作**：**在 `node.py` 的 `_do_hangup`**（已标注），复用 WS 信道，在连接关闭前完成
- 文件：`~/.agentlink/ledgers/<sid>.jsonl`（账本） + `<sid>.sig`（双方签名，独立存证）

### H3 降级分级（解决"分不清正常/攻击"）

```python
DOWNGRADE_CLASS_MAP = {
    "local_state_mismatch":     "noise",       # 大概率正常
    "reordered_frame":          "noise",
    "unexpected_cipher_change": "suspicious",  # 需关注
    "ratchet_desync_prolonged": "suspicious",
    "plaintext_downgrade":      "critical",    # 疑似攻击
    "signature_verify_failed":  "critical",
}
classify_downgrade(reason)  # 未登记的原因 → 保守归 suspicious（未知≠安全）
```
账本另计 `downgrade_count_by_class`，并给每条 frame 独立记 `cipher_suite`（冗余兜底）。

### H4 全量记录（解决"只记异常帧"）

`record_frame()` **无条件调用**——正常帧、降级帧都记。仅记 `payload_sha256`，不记 payload 本体。

## 三、接入三步（下一步施工）

### 步骤 1：会话建立时起账本
在 `secure_session.py` 的 `on_accept` / `on_ring` 成功后：

from agentlink.ledger import SessionLedger
self._ledger = SessionLedger(
    session_id=session_id,
    initiator=initiator_did, responder=responder_did, channel="ws",
    peer_name=self.state.name,

self._ledger.record_handshake(
    kex="X25519", cipher="ChaCha20-Poly1305", sig="Ed25519",
    did_verified=True, nonce=..., peer_fpr=...,

### 步骤 3：关闭 + 签名交换
在 `node.py` 的 `_do_hangup`（已标注），**WS 关闭前**：
```python
ledger.record_close(reason=reason, frames_in=self.frames_received, frames_out=self.frames_sent)
h = ledger.seal()
# 我方签名
my_sig = sign_keypair.sign(h)
await self._ws.send({"type": "ledger_sig", "session_id": sid, "ledger_hash": h, "sig": my_sig})
# 收对方（需在 reader loop 加"ledger_sig"消息类型处理）
peer_sig = await self._wait_ledger_sig(timeout=3.0)
ledger.record_signature_exchange(initiator_sig_received=..., responder_sig_received=...)
ledger.attach_signatures(initiator_sig=..., responder_sig=...)
ledger.save()
```

## 四、待决策点

## 六、已知限制（沿用 v0.2 设计稿的诚实标注）

- ❌ **私钥泄露** → 双签均失效（超 MVP 范围）
- ❌ **交换信道被劫持** → 属通联层问题（路①）
- ⚠️ **被审计代码自报** → 分级降低危害，但根本局限仍在（需独立见证，P2）
- ⚠️ **本地时钟** → seq 纳入哈希链做了轻量缓解
